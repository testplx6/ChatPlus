# La Classe Américaine — L'app des fans 🤠

Application web non officielle pour les fans de **La Classe américaine** (*Le Grand Détournement*, 1993), le film culte de Michel Hazanavicius et Dominique Mézerette entièrement monté à partir d'extraits de films Warner Bros. redoublés en français.

## Fonctionnalités

- **Générateur de citations** — une réplique culte aléatoire à chaque clic
- **Mur des répliques** — les citations incontournables du film
- **Quiz des vrais fans** — 8 questions avec explications et verdict final ("Vous êtes l'homme le plus classe du monde" ou... "Monde de merde")
- **Classe-o-mètre** — mesure déterministe de votre taux de classe (même nom = même score, la classe ne change pas d'un jour à l'autre)
- **Galerie des personnages** — George Abitbol, Dave, Peter, Steven, José...
- **Le film** — l'essentiel à savoir pour ne pas passer pour un tocard

## Lancer l'app

Aucune dépendance, aucun build : c'est un fichier HTML autonome.

```bash
# Ouvrir directement dans un navigateur
open classe-americaine/index.html

# Ou servir localement
npx serve classe-americaine
```

## Notes

Fait par des fans, pour des fans. Aucun extrait audio ou vidéo du film n'est utilisé — uniquement du texte et beaucoup d'amour. *La Classe américaine* appartient à ses ayants droit.
